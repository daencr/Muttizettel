Für alle, die 16 oder 17 Jahre alt sind:

- **Bis 24:00 Uhr** darfst du ohne Begleitung bleiben.
- **Länger** nur mit Muttizettel und deiner volljährigen Aufsichtsperson vor Ort.
- **Mitbringen:** Muttizettel ausgefüllt und unterschrieben, dazu deinen Ausweis.

- **PDF austauschen:** Neue Datei unter demselben Namen hochladen, dann bleiben alle Links und QR-Codes gültig.
- **PDF umbenennen:** Den Dateinamen zusätzlich an beiden Stellen in der `index.html` anpassen.
- Änderungen sind nach ein bis zwei Minuten online. Die Seite läuft über GitHub Pages aus dem Zweig `main`.
